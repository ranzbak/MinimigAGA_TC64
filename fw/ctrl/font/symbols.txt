# The OSD text layer's own symbol glyphs (fw/ctrl/tools/mkfontmem.py).
# Drawn for this project for the 8 x 16 cell, under the repository's
# licence (GPL-3).  The font is put together from three sources:
#   0x20-0x7E   Spleen 8x16 (font/spleen-8x16.bdf, BSD-2-Clause, font/LICENSE.spleen)
#   the glyphs the menu uploads when it opens (osd_icons.h: lines, corners,
#               the change and submenu arrows, the category icons; the value
#               bar computed as ui.c ui_glyphs does), so the ROM font and the
#               font RAM of an open menu are the same
#   this file   everything else that is not blank
# Format: "glyph 0xNN <name>", then 16 rows of 8 pixels, '#' set, '.' clear,
# the top row first.  Blank lines and lines starting with '#' + space are
# comments between glyphs.
